WHAT'S LIVE ON THE WEBSITE NOW
====================================

BUG FIXES (things that were broken and now work):
- Adding a product/service to a Job Card now actually shows up after you
  refresh the page or reopen it. (It was saving to the database correctly
  before, but the page wasn't re-reading it back — now fixed.)
- The Jobs list page: clicking a job now reliably opens it. Before, on most
  normal desktop screen sizes, clicking did nothing visible.
- The Jobs list page no longer shows "Unknown Client" / "Unknown Machine"
  for real jobs with real data — that was a display bug, not bad data.
- Notes linked to a customer from the Dashboard now show up on that
  customer's own page (they were being saved but never displayed there).
- You can now edit an existing product/service line on a Job Card, not just
  add or delete one.
- The "Machine Type" field on the Add/Edit Machine form now actually saves
  (it existed on screen but was silently ignored before).
- Photo uploads on Log Service and Book In now actually save to the record
  (pending migration 0020 above — the code is fixed, needs the database
  column).

NEW FEATURES:
- Settings page (visible to Administrators only): Job Card configuration
  (job numbering prefix, default status, default quantities, which
  statuses/line types are available), and a Products & Services catalogue
  you can manage yourself (add/edit/archive products and services with
  prices) — these now feed directly into the "Add Line" picker on Job
  Cards.
- Customer Import tool (Settings > Data Management) — upload an Excel file
  from Pastel, map the columns, preview what will be imported, see
  duplicates flagged, then confirm. Built to be reusable for future
  imports, not a one-time script.

DASHBOARD:
- Greeting now says "Good morning / afternoon / evening, [your real name]"
  based on the time of day, with the current date and time shown
  underneath, updating live while the page is open.

CALENDAR:
- Fixed: the calendar now correctly switches between month view and list
  view when you resize the browser window or rotate your device (it used
  to only check this once when the page first loaded).

LOGIN PAGE:
- Reduced a large empty gap that appeared above the login form on mobile
  phones.

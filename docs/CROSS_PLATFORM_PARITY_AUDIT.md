correct but has had no independent execution at all. Every row cites the evidence, not just a
verdict — check `docs/ai-memory/SESSION_LOG.md`/`KNOWN_ISSUES.md` for the full narrative behind
any row before treating it as ground truth in a much later session, since this file is a snapshot,

## What's genuinely left, in the order the roadmap itself recommends

1. **Phase 5's actual blocker** (KB 7-day signed-URL bug) — a real, disclosed, live production bug independent of this initiative's phase numbering. Fixing it unblocks Android KB upload too.
2. **Phase 10, web half** (dark mode / theming for `frontend/`) — a separate, larger, cross-file Tailwind initiative.
3. **Phase 13** (global responsiveness/UX final sweep) — deliberately last, since it's supposed to sweep everything above, most of which needed to actually be done first.
4. **This table itself** should be re-generated (not hand-patched) once the above land, since a stale parity table is worse than an absent one.
